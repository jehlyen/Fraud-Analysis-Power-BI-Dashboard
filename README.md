The cleaned dataset was imported into **Power BI** to create an interactive fraud analysis dashboard.

The dashboard was designed to provide both a high-level overview of fraud activity and the ability to drill into specific risk factors through interactive filters.

### Dashboard Features

The dashboard includes:

* Total transaction count
* Average order value
* Overall fraud rate
* Total fraudulent transactions
* Fraud percentage by time of day
* Fraud percentage by payment method
* Fraud percentage by product category
* Filtering by transaction month
* Filtering by account age
* Filtering by device type

### Interactive Filtering

Power BI slicers allow users to dynamically filter the dashboard based on different transaction characteristics.

Examples include:

* **Month**
* **Account Age**
* **Device Used**

These filters allow users to investigate whether fraud patterns change across different customer and transaction segments.

The visual design uses a dark, technology-focused theme with high-contrast visual elements to emphasize fraud-related metrics and make the dashboard easier to interpret.

### Dashboard Design Approach

The dashboard was structured around three primary questions:

**1. How much fraud is occurring?**

KPI cards provide an immediate view of transaction volume, average order value, fraud rate, and total fraudulent transactions.

**2. Where is fraud risk concentrated?**

Charts compare fraud percentages across payment methods, product categories, and time periods.

**3. Can users investigate specific segments?**

Interactive slicers allow users to filter the analysis and investigate how fraud patterns change across months, account ages, and device types.
